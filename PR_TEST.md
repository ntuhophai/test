# Pull request workflow test

This document is a small test contribution for `ntuhophai/test`.

The repository owner can review this file in the pull request's **Files changed** tab, then merge or close the pull request.

For an external contributor, the usual workflow is:

1. Fork the initialized public repository.
2. Create a branch in the fork.
3. Add or edit files and commit the changes.
4. Push the branch to the fork.
5. Open a pull request targeting the original repository's `main` branch.

This test contains no model weights, research data, or executable code.
